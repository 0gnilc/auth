# 1.0.0-rc.1 升级说明

## 升级来源

这是统一版本体系的首个候选版本。目前只支持全新安装；仓库此前的 `1.0.0` 与 Vben 的 `5.7.0` 不是已发布产品版本。历史未标记环境必须先审计实际代码、数据结构和权限数据，编写独立迁移并验收，不能直接声明已处于本基线。

## 数据库

基线为 `baseline-1`。新库先按 `apps/server/deploy/sql/README.md` 在同一个连接执行 `01` 至 `07` 初始化脚本，再创建迁移历史表。基线文件校验和与顺序由 `apps/server/deploy/migrations/manifest.json` 记录。初始化完成后按迁移说明记录基线，产品应用不会在启动时执行迁移。

本版本没有增量迁移。已有数据库不得重放初始化 SQL 来代替升级。

## 停机与会话

首次切换到存储命名空间 `gnilc-auth-admin-storage-v1` 时，浏览器旧偏好不自动导入，用户需要重新登录。此次变化不主动撤销后端已有会话；它们仍按现有过期/撤销规则处理。后续兼容版本继续使用相同存储命名空间。

全新安装不涉及旧服务停机；替换已有服务必须另行评估其认证和数据库兼容性。

## 回滚

首个候选版本没有经过验证的旧产品版本可供回滚。部署失败时停止新服务并保留诊断信息；数据库不得用反向 DDL 猜测恢复。历史环境切换前必须备份并验证恢复流程，在单独的迁移方案中明确回滚目标。
