# 管理员角色

`admin` 是管理员必需的基础访问角色，用于当前用户资料、修改密码、菜单和动态语言包。创建管理员或替换其角色时始终补齐该角色；通用 RBAC 解绑也不能移除现存管理员的基础角色。

`rbac:manager` 管理管理员、角色、权限与菜单，并能编辑这些资源引用的动态文案。

`i18n:manager` 管理全局动态国际化消息。它不授予管理员和 RBAC 管理权限。

初始化脚本创建默认管理员并维护基础角色；普通管理角色的后续解绑不会在重复初始化时恢复。自定义角色可按环境组合权限。

菜单访问码控制界面显示，API Permission 才是服务器授权依据。角色定义、Permission 和菜单的内置标记保护定义，不冻结普通授权关系。

角色与权限基线由 [部署 SQL](../../apps/server/deploy/sql/README.md) 维护，API 集成测试验证基础访问、RBAC 管理、国际化管理和拒绝响应矩阵。
